# Resume AI API

This project provides an API for analyzing resumes using the Hugging Face GPT-2 model. It takes resume text as input and provides AI-driven improvement suggestions.

## Features

- Analyze resumes and suggest improvements
- Simple POST API endpoint
- Powered by Hugging Face's API

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/resume-ai-api.git
   cd resume-ai-api
   ```

# Resume AI Frontend

This is the frontend for the AI-powered resume analysis system. It allows users to input their resume text and get suggestions for improvement from the backend.

## Setup

1. Clone the repository.
2. Navigate to the `frontend/` folder.
3. Run `npm install` to install dependencies.
4. To start the development server, run `npm start`.

## Testing

Make sure the backend server is running at `http://localhost:3000`.

Use the form to input resume text and analyze it. The result will be displayed below the form.
